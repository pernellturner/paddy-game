# Paddy's moves

One input, one move. This is what the buttons do in the Practice Room for base Paddy. Nothing here changes a control that already worked.

Forward means the way he is facing. Back means the other way.

## Claw

| Input | Move | Notes |
| --- | --- | --- |
| Tap | Next punch in the string: Jab, then Cross, then Hook, then Uppercut, then Jab again | He stays on the ground |
| Hold, then let go | Haymaker. If you tapped Forward just before, it is a Power Jab | Wind-up starts if you keep holding |
| Hold, then Up | Power uppercut (the rising launcher) | |
| Forward + Claw | Jab. A second forward jab in a row is the slipping jab | |
| Back + Claw | Cross | |
| Down + Claw | Body shot | |
| Up + Claw, quick | Uppercut, feet stay down | |
| Up + Claw, held | Rising launcher | |
| In the air, tap | Air swipe. After a double jump, air spin | |
| In the air, Down + Claw | Dive claw | |
| Double-tap | Roundhouse kick. A high kick with a hit on the extension, then he blends back to guard | Two Claw taps close together, with no direction. A normal one-two is slower and stays Jab, Cross |

| Hold, then let go | Shadow Pounce. Crouch wind-up, then a longer harder leap | |
| Down + Pounce | Low Pounce. A short low leap and a swipe | This used to do nothing. It is a new fill for an empty slot |
| Forward + Pounce | Same as a tap Pounce, aimed forward | |
| Back + Pounce | Back swipe | |
| Up + Pounce | Pop pounce, a higher hop | |
| In the air, tap | Small hop | |
| In the air, hold | Shadow pounce hop across to the dummy | Different from the ground hold, which is the leaping Shadow Pounce |
| Double-tap | No separate double-tap. Two pounces in a row are just two pounces | Used in the Pounce Crash string |

## Directions alone

| Input | Move | Notes |
| --- | --- | --- |
| Tap Up | Jump | |
| Up again in the air | Double jump | |
| Double-tap Up | Sky pounce | |
| Tap Down | Crouch. A very fast tap can also be a weave | Both exist. Holding Down is always the crouch |
| Double-tap Down | Cat slide | |
| Down, Down, Up | Backflip. A backward dodge with a moment where he cannot be hit | The two Downs alone are still the cat slide. Up has to follow quickly |
| Hold Forward | Walk or run forward | |
| Double-tap Forward, let go | Dash. Claw during it is a dash strike | |
| Double-tap Forward, then Down | Forward roll. He cannot be hit while he is off the ground | Down by itself is still the crouch. The roll only follows a fresh dash |
| Double-tap Forward, then Up | Front flip | Up by itself is still the jump. Up has to follow the dash quickly, after you let go |
| Double-tap Forward, and keep holding | Slide. He goes along the ground and can hit | A quick double-tap that you let go is still the dash |
| Down + Forward + Tail | Capoeira kick. A low spinning kick that hits | Down+Tail alone is still the sweep. Forward+Tail alone is still the trip |
| Hold Back | Walk backward. He does not turn around | |
| Double-tap Back, let go | Turn around | The only turn |
| Double-tap Back, then keep holding | Back dash | |

## Flagged

| What | Why |
| --- | --- |
| Down + Pounce used to do nothing | The press was swallowed. It is now Low Pounce |
| Air Blink hold and ground Pounce hold both say Shadow | They are different moves. The ground one leaps. The air one hops onto the dummy |
| Tap Down can weave or crouch | A very fast tap weaves. Holding Down crouches |
| No Hunt direction moves | Left empty on purpose so the buttons you already know stay put |
| Land from a double jump or a ground slam | Power landing. A short slam and recovery. Any button cancels it | |
| Knocked over in Spar | Knockdown. Plays once, holds the last frame, then he gets up. Any button gets him up sooner | |

## Timed strings

Press the next button within about a third of a second. On the beat (a bit quicker) you get an extra flash. Each string ends in a named hit.

| Name | Presses | Finisher |
| --- | --- | --- |
| Slip Finish | Claw, Claw, Forward+Claw, Claw | SLIP FINISH |
| Pounce Crash | Pounce, Pounce, Down+Pounce | POUNCE CRASH |
| Body Line | Claw, Down+Claw, Claw | BODY LINE |
| Rising Line | Claw, Up+Claw, Claw | RISING LINE |
| Tail Blink | Tail, Tail, Blink | TAIL BLINK |
| Pounce Jab | Pounce, Claw, Claw | POUNCE JAB |
| Sky Mix | Jump, Pounce, Claw | SKY MIX |
| Four Claws | Claw, Claw, Claw, Up+Claw | FOUR CLAWS |
| One-Two Kick | Claw, Claw, Roundhouse | ONE-TWO KICK |
| Roll Spin | Forward roll, then the capoeira kick | ROLL SPIN |
| Slide Launch | Slide, then Up+Claw | SLIDE LAUNCH |

## Linking and finishes

The roundhouse, backflip, roll, front flip, slide, and capoeira kick keep the combo going when they hit. Press the next button during the move. It is remembered and comes out as the move finishes, so a string does not have to be perfect.

Once the combo counter is at 3, press Claw and Tail together, with no direction. That is the finish. It gets easier and bigger as the combo grows.

| Combo | Tier | What you see |
| --- | --- | --- |
| 3 or 4 | Power | Capoeira kick, a short stop, a small zoom, and the dummy pops up |
| 5 to 7 | Big finish | Front flip, a longer stop, a little slow motion, and a higher launch |
| 8 or more | Ultimate | Forward roll, a big stop, slow motion, and the dummy flies and bounces |

The words sit along the top. Paddy's pose stays on screen.
